## 🌟 What is Titan Codyssey?

An open-source educational coding platform designed for **toddlers to teens** — teaching programming through:
- 🧩 **Visual blocks** for toddlers (no reading required)
- 🐍 **Real languages** for kids (Python, JavaScript)
- ☕ **Professional paths** for teens (Java, C++, Git)

**Gamified with Git concepts:** Lessons = branches, Steps = commits, Completion = merge. Kids learn version control while having fun!

**Vision:** Mobile-first coding education for every village student in India. 🇮🇳
